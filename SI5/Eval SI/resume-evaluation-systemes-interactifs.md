# Évaluation des Systèmes Interactifs — Résumé ultra-court

## 1) Bases & types d’évaluation
- Évaluation = méthodes tout au long du cycle; plus tôt = moins coûteux.
- Formative (avant/pendant) : améliorer, qualitatif, thinking aloud.
- Summative (après) : valider/comparer, quanti (taux succès, temps).
- Familles : inspection (experts), tests utilisateurs, enquêtes, modélisation.

## 2) Tests utilisateurs (protocole)
- Mesures clés : efficacité (succès), efficience (temps), satisfaction (SUS, NASA-TLX).
- Prépa : objectifs/hypothèses, tâches (warm-up + principales), métriques + baseline.
- Conduite : accueil, consentement, pré‑interview, tâches + thinking aloud, post‑questionnaire, debrief.
- N ≈ 5 utilisateurs suffit souvent pour qualitatif.

## 3) Modèles & questionnaires
- Nielsen : learnability, efficiency, memorability, errors, satisfaction.
- ISO 9241‑11 : efficacité, efficience, satisfaction.
- SUS : 10 items, score = somme ajustée × 2,5; moyen ≈ 68.

## 4) Expérimentation contrôlée & stats
- VI (manipulée), VD (mesurée), variables de contrôle.
- Designs : between (plus de sujets, moins d’apprentissage) vs within (plus puissant, effet d’apprentissage → contrebalancer).
- p‑value : p < 0,05 = significatif.
- Choix tests : t‑tests / ANOVA si normalité; sinon Wilcoxon, Mann‑Whitney, Friedman, Kruskal‑Wallis.

## 5) Eye tracking (oculométrie)
- Fixations (200–300 ms) = traitement; saccades = “aveugle”.
- PCCR + calibration; contraintes : lunettes, lumière, maquillage.
- Visualisations : gaze plot, heatmap, AOI.
- Métriques : TTFF, durée fixation, count, revisits (attention à l’interprétation).
